# Purehaven Cleaning Co. Website

A responsive static website for Purehaven Cleaning Co., built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server.

## Estimate form email

The estimate form sends submissions to `purehavendish@gmail.com` through the Google Apps Script endpoint configured in `script.js`. See [GOOGLE_APPS_SCRIPT_SETUP.md](GOOGLE_APPS_SCRIPT_SETUP.md) for deployment instructions.

The Apps Script web app is publicly callable so the website can submit estimate requests. Do not treat its URL as a password or secret; keep spam protection enabled and monitor Apps Script executions.
